# Start here

This package contains the materials for the **NexaWorks Product Development Challenge**.

Recommended order:

1. Read either `Product_Development_Challenge_EN.docx` or `Product_Development_Challenge_JA.docx`.
2. Inspect `candidate_dataset_reference.xlsx` to understand the scenario.
3. Treat `candidate_dataset.json` as the canonical machine-readable dataset.
4. Use `candidate_dataset.schema.json` to validate the expected structure.
5. Use `SUBMISSION_README_TEMPLATE.md` when preparing your submission.

The submission deadline is communicated separately. The way you organize your working time is up to you.

All company names, customer names and figures in this package are fictional.
